# Artes do jogo

As ilustrações desta pasta são vetoriais e ficam empacotadas com o jogo, sem chamadas de rede.

- `outpost-banner.svg`: cena polar usada no cabeçalho do painel de suprimentos.
- `items/field-kit.svg`: arte padrão para achados e itens de sobrevivência.
- `items/weapon-cache.svg`: arte para armas e munições.
- `items/anomaly-shard.svg`: arte para itens anômalos.

O saque e o inventário escolhem a ilustração pelo campo `category` do item. As prévias geradas no OpenArt nesta sessão vieram com marca d’água sobre a imagem inteira; por isso não são usadas na interface nem incluídas no pacote.
